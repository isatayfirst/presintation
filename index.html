Теория 1

Шейкерлік сұрыптау деген не?

Алгоритмнің идеясы

Шейкерлік сұрыптау (Cocktail Shaker Sort) массивті екі бағытта кезекпен аралап шығады. Жолда көрші екі элементті салыстырады. Сол жақтағысы үлкен болса, олардың орнын алмастырады.

Екі бағыттағы өту

→Солдан оңға: ең үлкен элемент массивтің соңына жетеді.
←Оңнан солға: ең кіші элемент массивтің басына жетеді.

Әр өтуден кейін бір элемент өз орнына тұрады, сондықтан тексерілетін бөлік екі жақтан тарыла береді.

Көпіршікті сұрыптаудан айырмашылығы

Көпіршікті сұрыптау (Bubble Sort) тек солдан оңға жүреді. Сондықтан соңында тұрған кіші элемент әр итерацияда бір-ақ орынға жылжып, басына баяу жетеді. Шейкерлік сұрыптау кері өтуде оны бірден басына апарады.

Неге «шейкер» деп аталады?

Алгоритм массив бойымен ары-бері қозғалады: оңға, солға, қайтадан оңға. Бұл коктейль шайқайтын шейкердің қозғалысына ұқсайды.

Теория 2

Күрделілік және қолдану

Ең жақсы жағдайO(n)Массив бұрыннан сұрыпталған: бір өту жеткілікті
Орташа жағдайO(n²)Элементтер кездейсоқ ретпен тұр
Ең нашар жағдайO(n²)Массив кері ретпен тұр
ЖадO(1)Қосымша массив керек емес
ОрнықтылықИәТең элементтердің бастапқы реті сақталады

Мұндағы n — массивтегі элементтер саны. O(n²) күрделілігі мынаны білдіреді: элементтер 2 есе көбейсе, жұмыс шамамен 4 есе артады.

Артықшылықтары

  • Түсінуге де, жазуға да оңай.
  • Қосымша жад қажет етпейді.
  • Дерлік сұрыпталған массивте тез аяқталады.
  • Кіші элементтер соңында тұрса, көпіршікті сұрыптаудан аз өту жасайды.

Кемшіліктері

  • Үлкен массивтерде баяу, себебі күрделілігі O(n²).
  • Жылдам сұрыптау (Quick Sort) мен біріктіру арқылы сұрыптаудан (Merge Sort) әлдеқайда баяу.

Қашан қолданамыз?

  • Сұрыптау алгоритмдерін үйренгенде.
  • Элементі аз шағын массивтерде.
  • Деректер дерлік сұрыпталып тұрғанда.

Дайындық және бірінші өту

Қызғылт сары жол: элементтердің орны алмасатын жер

1Айнымалыларды жариялау
start = 0             # сол жақ шекара
end = len(arr) - 1    # оң жақ шекара
swapped = True        # алмастыру болды ма?

start пен end сол және оң жақ шекараны сақтайды, соңғы индекс len(arr) - 1. swapped белгісі: өтуде алмастыру болмаса, массив сұрыпталған және цикл ерте аяқталады.

2Негізгі цикл
while swapped:
    swapped = False

Цикл swapped мәні True болғанша жұмыс істейді. Әр итерацияның басында оны False етеміз: толық өтуде (оңға да, солға да) ештеңе алмаспаса, цикл аяқталады.

3Бірінші өту: солдан оңға →
for i in range(start, end):
    if arr[i] > arr[i + 1]:
        arr[i], arr[i + 1] = arr[i + 1], arr[i]
        swapped = True

Цикл start-тан end-ке дейін жүріп, көрші arr[i] мен arr[i + 1] элементтерін салыстырады. Сол жағы үлкен болса, орнын алмастырады, сондықтан ең үлкен элемент соңына жетеді.

4Тексеру және шекараны жылжыту
if not swapped:
    break       # алмастыру жоқ: массив сұрыпталған
end -= 1        # ең үлкен элемент өз орнында
swapped = False

Алмастыру болмаса, массив сұрыпталған: break арқылы шығамыз. Болса, end -= 1 оң шекараны азайтады, ал swapped кері өтуден бұрын қайта False болады.

Кері өту және нәтиже

5Екінші өту: оңнан солға ←
for i in range(end - 1, start - 1, -1):
    if arr[i] > arr[i + 1]:
        arr[i], arr[i + 1] = arr[i + 1], arr[i]
        swapped = True

Енді алгоритм кері жүреді: end - 1-ден start-қа дейін. Сол жақ элемент үлкен болса, орнын алмастырады, сондықтан ең кіші элемент басына жетеді.

6Сол шекараны жылжыту
start += 1

Кері өтуден кейін ең кіші элемент орнында тұр, start бірге артады.

7Тізімді қайтару
return arr

Цикл аяқталған соң функция сұрыпталған тізімді қайтарады.

▶Толық код
def cocktail_shaker_sort(arr):
    # 1. Айнымалыларды жариялау
    start = 0
    end = len(arr) - 1
    swapped = True

    # 2. Негізгі цикл
    while swapped:
        swapped = False
        # 3. Бірінші өту: солдан оңға →
        for i in range(start, end):
            if arr[i] > arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]
                swapped = True
        # 4. Тексеру және шекараны жылжыту
        if not swapped:
            break       # алмастыру жоқ: массив сұрыпталған
        end -= 1        # ең үлкен элемент өз орнында
        swapped = False
        # 5. Екінші өту: оңнан солға ←
        for i in range(end - 1, start - 1, -1):
            if arr[i] > arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]
                swapped = True
        # 6. Сол шекараны жылжыту
        start += 1      # ең кіші элемент өз орнында

    # 7. Тізімді қайтару
    return arr
